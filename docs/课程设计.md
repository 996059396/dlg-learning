# 📐 课程设计

本文档定义 DLG 学习系统的**课程内容设计**：课程体系结构、单元/课时/节点组织、题型与判分语义、游戏化与复习机制、以及贯穿全部知识点的**知识图谱**（586 条）与**标准引用链**（137 条，联网核验结论）。

- 接口契约见 `docs/API.md`，数据表见 `docs/数据库schema.md`，运行维护见 `docs/运维手册.md`，部署见 `docs/部署指南.md`。
- 内容数据位于 `backend/data/courses/**`（JSON），`index.json` 是课程树权威白名单；判分答案键随内容 JSON 一起维护。

## 一、课程体系总览

三门课程 + 一个独立多选池，零基础直达电工考证：

| 课程 id | 标题 | 单元数 | 课时数 | 节点数 | 设计主线 |
| --- | --- | --- | --- | --- | --- |
| `electrician_prereq` | 电工零基础前置课程 | 4（e0–e3） | 60 | 568 | 小学零基础 → 初中物理 → 高中进阶 → 衔接《电路》 |
| `electrician_basics` | 初级电工理论 | 11（u1–u11） | 578 | 3736 | 万用表 → 电路基础 → 工具 → 继电器 → 石群《电路》全体系 |
| `electrician_exam` | 电工考证主线：安全与急救 | 13（s1–s13） | 65 | 677 | 考证 13 单元 + 全真模拟考 |
| （多选池） | `backend/data/exam/multi_select.json` | 1（`exam/ms_pool`） | 1 | 39 | 模拟考与错题卡共用的多选题池 |

> 合计 **704 课时 / 5020 节点**（`scripts/validate_content.cjs` 与 `scripts/check_data_integrity.cjs` 双确认）。三线总时长约 **39 小时**（前置 376 分钟 + 理论 1765 分钟 + 考证 195 分钟）。

三条路径的关系：

```
electrician_prereq（零基础入口）
   └─→ electrician_basics（u1–u11，理论主线）
         └─→ electrician_exam（s1–s13，考证主线，含模拟考）
```

### 课程定位

- **前置**：面向完全零基础。e0 用电的启蒙（生活比喻）；e1 初中物理（欧姆定律/串并联/家庭电路）；e2 高中进阶（电容电感/交流电/复数/运放直觉）；e3 衔接（邱关源记号、参考方向、KCL/KVL、方程组、戴维宁预告、万用表读表原理）。
- **理论**：以石群教授《电路》（邱关源第五版）为骨架。u1–u5 实操与工具；u6–u7 石群电路 I/II；u8–u11 微学习单元（一题一知识点，占课时大头）。
- **考证**：s1–s12 按考证考纲铺排（安全急救→仪表→电机控制→配电→照明→识图→电动机→接地防雷→高压→电子→变频 PLC→成套柜），s13 为综合模拟考单元。

## 三、题型与判分

### 3.1 节点类型（13 种，全量分布实测）

| 类型 | 数量 | 判分语义 |
| --- | --- | --- |
| `multiple_choice` 单选 | 1550 | `options[].is_correct` 或 `correct_answer` |
| `info` 讲解/铁律 | 1278 | 不判分（`gradeable:false`） |
| `true_false` 判断 | 1091 | `correct_answer`（`正确/错误` 或 `对/错`） |
| `fill_blank` 填空 | 919 | `acceptable_answers` 集合，服务端归一化比对 |
| `multi_select` 多选 | 39（池） | `options[].is_correct`；选项 id 会话级/卡片级重映射（C10） |
| `match` 连线 | 70 | `pairs`（五对连线，乱序渲染） |
| `sort` 排序 | 45 | `correct_order`（拖拽排序判序列） |
| `multimeter_challenge` 仿真 | 18 | `correct_setup` + `correct_display`（DT9205Pro 全流程仿真） |
| `simulation_dial` 旋钮仿真 | 3 | `correct_setup` |
| `simulation_danger` 危险仿真 | 3 | 安全操作判定（含子串判定） |
| `simulation_probe` 探针仿真 | 2 | `correct_probes` |
| `drag_drop` 拖拽 | 2 | `target_zone` + `distractors` |

### 3.2 判分语义（`backend/lib/grading.js`）

- 服务端 `gradeNode` 逐节点**重判**，客户端提交的 `correct` 字段不被信任；`gradeable` 为 false 一律判错（**fail-closed**）。
- 按题型取不同答案键：`correct_answer` / `acceptable_answers` / `options[].is_correct` / `pairs` / `correct_order` / `target_zone` / `correct_probes` / `correct_setup` / `correct_display`。
- 通过线：**accuracy ≥ 80** 才算 pass；sub-80 不计首次完成（可重试仍拿全额首次奖励）。
- `completed` 单调：曾 pass 的课不被 sub-80 重试降回未完成（防 pass/fail 交替重复领奖）。

### 3.3 内容门禁

任何内容改动必须过两道门禁（见 `docs/测试说明.md`）：

1. `scripts/validate_content.cjs` —— 结构/字段/引用完整性，**0 ERROR**（当前 5020 节点）。
2. `scripts/grade_scan.cjs` —— 全量可判分节点**自评 100% 自洽**（当前 3742 判分节点，非 100% = 0）。
3. `scripts/check_data_integrity.cjs` —— 错题卡/进度/外键完整性哨兵（704 课时，零孤儿，无 NULL node_id）。

## 四、游戏化与错题复习

> 经济系统与接口细节见 `docs/API.md`，表结构见 `docs/数据库schema.md`。这里只讲**设计意图**。

### 4.1 激励设计

| 机制 | 设计意图 |
| --- | --- |
| 红心（5 上限，15 分钟免费补 1 心） | 限制错误练习吞吐，逼「先学再练」；服务端扣心，全对不耗心 |
| 金币（初始 500，商店消费） | 进度货币：首次 pass +5；错题复习信用可兑 +1 心 / +10 币 |
| 经验 XP（每日上限 150） | 进度与段位结算依据：满分 15 / pass 12 / 努力 +2；上限防刷 |
| 签到连胜（日结 10~100 币） | 日活钩子，连胜冻结块/护盾兜底 |
| 段位（bronze→diamond，周一结算） | 周循环目标 + 社交比较；有效分区缩放防小段位全员晋升 |
| 模拟考（100 题 / 45 分钟 / 80 及格） | 考证全真检验；首日首过 +30 币、pass +30 XP |

### 4.2 SM-2 错题复习

- 判错即入册（`mistakes` 表，含题目/答案**快照**，后续编辑内容不影响判分）。
- 到期队列分两层：**到期复习**（`review_count>0`，最久优先，硬顶 50）＋**今日新错**（`review_count=0`，硬顶 20）；`limit`(1–30)+`offset` 翻页。
- 复习判对 → SM-2 排程（间隔 1→6→…，EF ≥1.3）；间隔 ≥21 天 → mastered 出队。
- 判对一次记 1 单位「复习信用」（按错题去重），`practice-heal` 兑现（+1 心 / +10 币，单次 ≤20 单位）。
- 孤儿卡（节点已删）直接 mastered 出队，防「永无法 master」死锁。
- **多选池卡防刷**：错题卡不复用池内规范 id，每卡带 `remap_json`（池 id → 会话随机 `ms-xxxx`），重判时正确集随卡移动，脚本盲猜固定 id 无法刷分。

### 6.3 引用链的用途

- **教学设计依据**：每条知识点的标准支撑可追溯（S 维度），评审时能回答「为什么这样讲、依据是什么」。

## 七、内容维护红线

- **改动必须过门禁**：`validate_content.cjs`（0 ERROR）→ `grade_scan.cjs`（100% 自洽）→ `check_data_integrity.cjs`（零孤儿）。
- **判分答案键随内容 JSON 维护**：删/改节点前先跑完整性哨兵；产生孤儿卡用 `scripts/cleanup_data_hygiene.cjs` 清理，否则错题本卡死在无法 master 的卡片上。
