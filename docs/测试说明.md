# 🧪 测试说明

本项目的测试是 **Node 原生脚本**（`node:test` + 手写断言），零测试框架依赖，`npm test` 一键跑全量门禁。

## 一、一键全量门禁

```bash
cd backend
npm test
```

`npm test` 是一条 `&&` 串联的脚本链（见 `backend/package.json`），任一环节失败即整体失败：

| 环节 | 脚本 | 断言数 | 作用 |
| --- | --- | --- | --- |
| 内容校验 | `node ../scripts/validate_content.cjs` | — | 扫描全部课程 JSON，0 ERROR / 0 WARN 才算过 |
| 接口测试 | `node ../test_api.mjs` | 44 | 注册/登录/课程/进度/判分/金币/检查点/SM-2 |
| 里程碑测试 | `node ../smoke_milestone1.mjs` | 20 | 核心业务流程冒烟（练习→判分→奖励闭环） |
| 排行榜测试 | `node ../test_leaderboard_v2.mjs` | 12 | 段位/周结算/排行 |
| 结算测试 | `node ../smoke_settlement.mjs` | 14 | 周结算补账、当前周不被动、幂等 |
| 安全不变量 | `node ../test_security_invariants.mjs` | 19 | 错题卡脱敏缺席断言、register 独立桶、login-user-global 兜底、模拟考及格路径、多选 remap + 复习重映射、错题卡 5 类答案键剥离、rate_limit 桶、simulation_danger 负例 |
| 判分自洽 | `node ../scripts/grade_scan.cjs` | 3742 节点 100% | 遍历全部判分节点构建正确答案→判分 |
| 数据完整性 | `node ../scripts/check_data_integrity.cjs` | 704 lessons | 无孤儿节点、无 NULL node_id |

**共 109 断言**（判分自洽 / 数据完整性为扫描性质），全绿即发布门禁通过。

## 二、内容校验器（最重要的一道门）

```bash
cd backend
node ../scripts/validate_content.cjs
```

- 扫描 `backend/data/courses/` 与 `data/exam/` 下所有 JSON。
- 检查：id 全局唯一、node 结构完整、判分节点 `correct` 可被 `gradeNode` 判定、index.json 与目录一致等。
- 输出 `0 ERROR / 0 WARN / N 节点` 才算合格。
- **任何内容改动都必须过这道门**，防止把结构错误带进线上。

> 想确认「所有判分节点都能判 100%」？可运行判分扫描脚本（内容侧）：遍历全部节点用 `gradeNode` 构建正确答案→判分，期望 **0 个非 100%**。

## 三、常见场景

| 你改了 | 要跑什么 |
| --- | --- |
| 课程 JSON / 新增内容 | `validate_content.cjs` + `npm test` |
| 后端路由 / 判分逻辑 | `npm test`（接口与里程碑覆盖判分） |
| 前端组件 | `cd frontend && npm run build`（保证能构建）+ 手测 |
| 排行榜 / 结算 | `test_leaderboard_v2.mjs` + `smoke_settlement.mjs` |

## 四、测试数据隔离

测试用**独立 SQLite 库**（测试会话内建临时库 / 内存库），不碰真实 `app.db`，可放心反复运行。断言以「行为 + 落库结果」双验证，例如完成一课应同时更新 progress 且写入 node_results。
