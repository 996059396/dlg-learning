# 📚 DLG 电工学习系统 · 使用手册

> 面向使用者的完整手册：这是什么、怎么打开、怎么学、怎么用全部功能。适用于 **v1.0.3（稳定版，2026-08-17）**。

---

## 一、这是什么

**DLG 是一个电工考证备考平台**：从零基础到初级电工考证，一堂课一堂课地学，错了自动进错题本，考前还能全真模拟考。

- 内容：**3 大课程 / 29 单元 / 705 节微课 / 5029 个知识点**
  - **零基础前置**（e0–e3）：小学→初中→高中→衔接，没学过电也能上手
  - **初级电工理论**（u1–u12）：万用表、电路基础、基尔霍夫定理、运放、交流、三相电路
  - **考证主线**（s1–s13）：安全与急救→成套开关柜→全真模拟考，对齐真实低压电工理论机考
- 学习闭环：**微课精讲 → 服务端判分练习 → 错题自动进 SM-2 错题本 → 按时复习 → 考前模拟考**

## 二、三种打开方式

| 形态 | 怎么打开 | 适合 |
| --- | --- | --- |
| **浏览器（Web）** | 后端启动后浏览器访问 `http://localhost:3001` | 日常学习（主入口） |
| **桌面应用（Electron）** | `desktop/` 下已打包的安装包（Windows） | 像普通软件一样双击启动 |
| **手机/平板（PWA）** | 浏览器访问后「安装到主屏幕」 | 移动端学习（支持离线） |

### Web / 桌面一键启动（Windows）

后端脚本已配置开机自启与每日备份，正常情况直接双击桌面图标即可。若需手动启动：

```bash
# 一键启动（含守护，崩了自动拉起、每日 03:47 自动备份）
lib/dlg_server_guard.sh   # 由登录自启脚本自动运行，一般不用手动
```

需要手动起服务时：

```bash
cd backend
node server.js            # 启动后台（端口 3001）
```

> **Node 版本要求**：本应用需要 **Node ≥ 24**（内置的 Electron 桌面版已自带，无需另装）。用浏览器直连仅供开发预览。

## 三、第一次使用

1. 打开应用，进入**登录/注册**页。
2. 点「注册」，设用户名 + 至少 6 位密码。
3. 登录后默认进入课程首页。

> 演示账号：应用内置演示账号（「小电工」）可无注册体验。**正式学习建议注册自己的账号**，进度才会长期保存。

## 四、学习路径

### 4.1 选课 → 单元 → 微课

首页展示 3 门课程，点进去是单元（如「u1 万用表基础」），再进是微课。**建议顺序**：

1. 没电学基础的：先学 `零基础前置`
2. 学完衔接 → 进入 `初级电工理论`（u1 → u12）
3. 最终进入 `考证主线`（s1 开始）→ 全真模拟考

### 4.2 微课怎么学

每节微课由**讲解卡 + 练习题**组成：

- **讲解卡（📖）**：先看再答，正文讲清楚一个知识点
- **练习题**：单选题、判断题、填空题、连线题、排序题、万用表仿真操作等 12 种题型
- 提交答案由**服务端真实判分**——做对了得分，做错了进错题本
- 每节准确率 ≥ 80% 才算「通过」，通过给金币和经验的课程奖励

### 4.3 红心机制（答错的代价）

- 每题答错会**扣 1 颗红心**（最多扣到 0）
- 红心扣完再答错 → 该节练习会被挡下（`needsHearts`），需先补心
- **全对提交不消耗红心**，所以红心为 0 时仍然可以完整做会做的题
- 补心方式：
  - 等 **15 分钟自动回 1 颗**
  - 去**错题医疗包**复习错题，用复习信用换红心 + 金币
  - 商店买「补心」

## 五、错题本与复习（核心用法）

答错的题都会自动进**错题本**（SM-2 间隔重复，跟 Anki 同一套算法），系统会按科学间隔提醒你复习，防止「学过就忘」。

### 5.1 错题医疗包

- 点击「🏥 错题医疗包」进入复习
- 系统一次给一批到期错题：**顽固错题（连错多次 leech）排最前**，其次按遗忘风险从高到低
- 每张卡能看到「预测记得概率」和「来源章节」，忘了可点回讲义
- 判对：卡排程推进（间隔 1→6→…→21 天后 mastered，出队）；判错：重新进队列、下次更早再来

### 5.2 复习信用 & 兑换

- 每张卡**判对一次** → 记 1 单位「复习信用」（自动去重，刷不出来）
- 到「错题医疗包」右上角用信用**换红心 + 金币**（+1 心 / +10 币 每单位，单次最多兑 20）
- 这就是「越复习越有底气」的正循环

### 5.3 学习统计

「我的」页 →「📊 学习统计」：

- **留存率**：全部复习判对比例；再分 **young（间隔<21天）/ mature（≥21天熟卡）** 两档看新卡熟卡分别记得多牢
- **未来 7 天到期**：每天有多少复习/新卡到期，提前安排时间
- 上方还有**近 7 天复习曲线**：每天复习次数 + 正确率

### 5.4 导出到 Anki

「我的」页 →「错题导出（Anki 兼容）」→ 下载 TSV，可直接导入 Anki 在手机上刷。

## 六、全真模拟考（考证冲刺）

「模拟考」页支持两种模式：

| 模式 | 题量构成 | 时长 | 及格 | 用途 |
| --- | --- | --- | --- | --- |
| **全真（默认）** | 100 题（60 判断 + 40 单选） | 120 分钟 | 80 分 | 对齐真实低压电工理论机考 |
| **训练** | 100 题（60 判断 + 30 单选 + 10 多选） | 45 分钟 | — | 日常刷题训练 |

- 首场**首次通过** +30 金币、pass +30 经验
- 交卷逐题服务端判分，错题自动进错题本
- 「全真」模式有**防切屏**：切出考试界面超过阈值会被标记异常（异常卷仍算成绩，但扣发首过金币）——认真考，别切出去查答案
- 多选题选项顺序随机、选项编号每次考试都不同（防背「ABCD」位置）

## 八、离线使用（PWA）

- 学习时保持联网；网络断了也**可以离线看已缓存的课**
- 离线完成的练习会进本地队列，**联网后自动重判同步**（带幂等键，不会重复结算/重复发币）
- 建议：装到主屏幕（PWA）后体验最顺

## 十一、遇到问题

| 现象 | 处理 |
| --- | --- |
| 页面打不开 | 确认后端已启动（`http://localhost:3001`）且端口 3001 未被占用 |
| 红心 0 被挡 | 补心（等 15 分钟 / 医疗包复习 / 商店买补心）或全对提交 |
| 复习判分对不上讲义 | 以服务端实时重判为准（快照答案仅供回看） |
| 进度丢失 | 每日自动备份在 `backend/models/data/backups/`；升级前脚本 `scripts/backup_db.cjs` 可手动备份 |
