## 一、一句话定位

**DLG 是一个开箱即用的电工考证备考平台**：微课精讲 + 服务端判分练习 + 全真模拟考 + 游戏化激励（金币 / 红心 / 签到连胜 / 段位排行榜 / SM-2 错题复习），零基础一路学到初级电工考证。

- 本地仓库：`D:\dlg_project`（开发主仓）
- 公开仓库：`github.com/996059396/dlg-learning`（孤儿快照同步，不含内部审计/版权素材）
- 运行形态：Web（同源单文件部署） + PWA（离线可学） + Electron 桌面壳（三平台）

## 四、架构总览

```
浏览器 / PWA / Electron 壳
        │  HTTP（JSON / 静态资源）
        ▼
backend/server.js（单进程）
  ├─ Express 路由
  │    ├─ routes/auth.js      登录注册、会话（DB 不透明 token）
  │    ├─ routes/courses.js   课程、服务端判分、奖励、幂等提交
  │    ├─ routes/game.js      红心/金币/错题复习/排行榜/签到
  │    └─ routes/exam.js      全真模拟考（100题/45min）
  ├─ lib/grading.js           判分真源（13 种题型，fail-closed）
  ├─ models/database.js       建表 + 迁移 + 全部 SQL
  └─ middleware/              鉴权 / 限流
        │
        ▼
frontend/dist（静态站点，SPA fallback）
```

**判分与奖励一律以服务端为准**：客户端只提交「题目 id + 用户答案」，正确性、分数、金币/经验/红心全部在服务端完成。客户端 `correct` 字段不被信任。

- **3 门课程 / 29 单元 / 705 门课程微课（+多选池伪课时 = 706 课时）/ 5029 节点**（`scripts/validate_content.cjs` 实测），总时长约 39 小时：

| 课程 | 定位 | 单元 |

## 六、核心功能

### 6.1 学习闭环
- **微课精讲**：u8–u11 采用「一题一知识点」微课（教学卡 + 1~6 题），实时读盘、改 JSON 刷新即生效。
- **服务端判分**：全题型服务端真源化，客户端镜像本地反馈（已对齐归一化规则）。
- **红心门禁**：答错扣心（服务端），红心 0 拒错题提交、全对仍可过。

### 6.2 模拟考（双模式，价值锚）
- **全真模式（默认）**：100 题（60 判断 + 40 单选）/ 120 分钟 / 80 分及格 —— 对齐真实低压电工理论机考（应急〔2025〕59 号、应急管理部令第 19 号）。
- **训练模式**：100 题（60 判断 + 30 单选 + 10 多选）/ 45 分钟 —— 多选训练用途。入口可切换两种模式。
- **防作弊**：多选题选项顺序随机 + 选项 id 会话级重映射（`ms-xxxx`），盲猜 `{A,B}` 命中率 ≈1/45。
- 首日首过 +30 币、pass +30 XP；错题自动入 SM-2 错题本。

### 6.3 游戏化与复习
- 金币（商店：冻结块/2×经验/补心/连胜护盾）+ 经验（日上限 150）+ 红心（15 分钟免费补 1）。
- **SM-2 错题复习**：判错入册，复习判对排程推进（间隔 1→6→…），间隔 ≥21 天 mastered；复习判对记「复习信用」可兑红心/金币（封顶不丢）。
- **段位排行榜**：bronze→diamond，每周一 00:00（上海时区）自动结算升降段；小段位有效分区缩放。
- **离线学习（X02）**：离线完成的课程入队（`client_request_id` 幂等），联网后服务端重判同步，绝不二次铸币。

### 6.4 安全与防作弊
- 会话 token 存 **SHA-256 哈希**（不透明、不可逆），滑动续期 30 天 / 上限 90 天。
- 管理接口 `ADMIN_TOKEN` fail-closed（未配置 503）；限流 9 个桶（register 独立 5/15min、login 双因子、admin 30/15min、lesson-views 240/15min 等）。
- 错题卡答案键 5 类题型全剥离，唯一揭示答案的接口是提交复习后。
- 多选池错题卡逐卡重映射（`remap_json`），脚本盲猜无法刷分。
- 课程接口答案键（鉴权门）+ `lesson-views` 限流；**已知取舍见 CLAUDE.md**。
