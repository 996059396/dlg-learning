# 📦 课程内容结构指南

课程内容全部是 **JSON 文件**，不依赖数据库。这是本项目最重要的可扩展面。

## 一、存放位置

```
backend/data/
├── courses/
│   ├── index.json              # 课程目录索引（前端课程树用）
│   ├── electrician_prereq/     # 电工零基础前置（4 单元）
│   │   └── e1_intro.json       #   一个单元一个 JSON
│   ├── electrician_basics/     # 初级电工理论（11 单元）
│   └── electrician_exam/       # 电工考证主线（13 单元）
└── exam/
    └── multi_select.json       # 多选题池（模拟考用）
```

> ⚠️ **两种文件结构都可能出现**：
> - 有的文件是**数组**：`[ { id, units: [...] }, ... ]`（每元素是一整门课）
> - 有的文件是**单个对象**：`{ id, lessons: [...] }`（顶层直接是课列表）
>
> 写脚本处理内容时，务必两者都兼容（`Array.isArray(j)` 判断）。

## 二、层级结构

```
课程 course ──► 单元 unit ──► 课 lesson ──► 节点 node
```

```jsonc
// backend/data/courses/<course>/<unit>.json
{
  "id": "u1_intro",
  "title": "初识电工",
  "lessons": [
    {
      "id": "l1_what_is_electricity",
      "title": "什么是电",
      "nodes": [
        {
          "id": "l1_what_is_electricity_n1",   // 全局唯一
          "type": "info",                        // 教学卡（不判分）
          "content": "电流的本质是电荷的定向移动……"
        },
        {
          "id": "l1_what_is_electricity_n2",
          "type": "multiple_choice",             // 判分题型
          "question": "下列哪个是电流的单位？",
          "options": [
            { "id": "A", "text": "伏特（V）" },
            { "id": "B", "text": "安培（A）" },
            { "id": "C", "text": "欧姆（Ω）" },
            { "id": "D", "text": "瓦特（W）" }
          ],
          "correct": "B",
          "explanation": "电流单位是安培（A）。伏特是电压，欧姆是电阻，瓦特是功率。"
        }
      ]
    }
  ]
}
```

## 三、节点类型（type 字段）

| type | 是否判分 | 关键字段 | 数量 |
| --- | --- | --- | --- |
| `info` | 否 | `content` 教学卡正文 | 1,278 |
| `multiple_choice` | ✅ | `question` + `options[{id,text}]` + `correct`（选项字母） | 1,550 |
| `true_false` | ✅ | `question` + `correct`（`true`/`false`） | 1,091 |
| `fill_blank` | ✅ | `question`（含 `__` 空位）+ `correct`（答案文本） | 919 |
| `match` | ✅ | `question` + `left`/`right` 两列 + `correct`（配对关系） | 70 |
| `sort` | ✅ | `question` + `options` + `correct`（正确顺序） | 45 |
| `multimeter_challenge` | ✅ | 万用表实操模拟（拨盘/表笔/读数） | 18 |
| `simulation_danger` | ✅ | `correct_sequence`（操作序列）+ `danger_action`（危险操作），答对发 `'安全操作'` | 3 |
| `simulation_dial` / `simulation_probe` | ✅ | 万用表拨盘/表笔专项模拟 | 5 |
| `drag_drop` | ✅ | 拖拽配对 | 2 |
| `multi_select` | ✅ | `question` + `options` + `correct`（字母数组，无序等价）——**仅存在于模拟考多选题池**（`data/exam/multi_select.json`），课程课内未使用 | 10（池内） |

判分核心在 `backend/lib/grading.js` 的 `gradeNode(node, userAnswer)`。

## 四、判分规则要点（易踩坑）

1. **空白不敏感**：判分前会去掉所有空白字符、全角转半角。所以 `"安培（A）"` 与 `"安培(A)"` 等价。
2. **多选题判无序**：`correct` 是选项字母数组，提交顺序任意都算对（集合相等）。
3. **解释字段**：判分节点的 `explanation` 是学生答错后看到的解析，务必写清「为什么」，不要只复述答案。
4. **MC 选项排序**：`options` 建议按 `id` 字母序排列（A/B/C/D），前端按数组顺序显示字母。

## 五、新增一门课 / 一个单元的步骤

1. 新建 `backend/data/courses/<course_id>/<unit_id>.json`（结构见上）。
2. 若没有该课程目录，创建目录并给它建 `index.json`（课程元信息）。
3. 更新 `backend/data/courses/index.json` 的 `units` 列表与 `lesson_count`。
4. 跑校验：
   ```bash
   cd backend
   node ../scripts/validate_content.cjs   # 期望 0 ERROR
   ```
5. 跑全量门禁：
   ```bash
   npm test   # 期望 70 断言全绿
   ```
6. 重启后端（内容虽是实时读盘，但 index 变更建议重启确认）。

## 六、内容质量红线

- `id` 必须全局唯一（校验器会查）。
- 判分节点必须有 `correct` 且能被 `gradeNode` 判 100%（`scripts/validate_content.cjs` 覆盖）。
- `info` 教学卡不要带「判定语」（如「回答正确」），那是判分节点解释的专属。
- 题干与选项引用具体数字/标准时以国标（GB/T）为准，标注适用范围（如美国 NEC 语境要注明）。
