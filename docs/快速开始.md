# 📖 新手引导 / 快速开始

这份文档写给第一次接触本项目的开发者：**5 分钟跑起来，然后知道去哪改、去哪看**。

## 一、环境要求

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 24 | 后端与前端共用（better-sqlite3 预编译二进制在 Node 20 段错误，勿用） |
| npm | 随 Node 自带 | 无需全局安装其它工具 |

无需数据库安装、无需 Redis、无需 Docker。数据是单文件 SQLite。

## 二、首次运行（5 分钟）

```bash
# 1) 后端依赖
cd backend
npm install

# 2) 前端依赖
cd ../frontend
npm install

# 3) 启动后端（终端 A）
cd ../backend
node server.js
#    看到 "DLG Learning Server running on http://0.0.0.0:3001" 即成功

# 4) 启动前端（终端 B）
cd ../frontend
npm run dev
#    看到 "Local: http://localhost:5173/" 即成功
```

浏览器打开 **http://localhost:5173**：

1. 右上角注册一个新账号（或登录已有账号）
2. 进入课程树，从「电工零基础前置」开始
3. 学完微课，点「开始练习」，做对题赚金币、攒生命
4. 主线课程第 13 单元有 **🧯 全真模拟考**入口，100 题 / 45 分钟 / 80 分及格

> 首次启动会在 `backend/models/data/app.db` 自动建库并写入示例内容数据，无需手动初始化。

## 四、常用命令速查

| 命令 | 作用 |
| --- | --- |
| `cd backend && npm test` | 全量测试门禁（109 断言） |
| `node scripts/validate_content.cjs` | 只跑课程内容校验（0 ERROR 才算合格） |
| `cd frontend && npm run build` | 前端生产构建（产物 `frontend/dist`） |
| `cd frontend && npm run dev` | 前端开发模式（热更新） |
| `node server.js` | 后端生产模式（同时托管前端 dist） |

## 五、环境变量

| 变量 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ADMIN_TOKEN` | 管理功能需要 | 无（缺省则管理接口 503） | `x-admin-token` 请求头鉴权 |
| `PORT` | 否 | `3001` | 后端端口 |
| `HOST` | 否 | `0.0.0.0` | 后端监听地址 |
| `CORS_ORIGINS` | 否 | 前端本地域名 | 逗号分隔的允许跨域来源 |

Windows PowerShell 设置示例：

```powershell
$env:ADMIN_TOKEN = "改成你的管理口令"
node server.js
```

## 六、常见问题

- **注册时提示用户名已存在** → 数据库里已有同名用户，换一个用户名或直接登录。
- **管理接口返回 503** → 没设置 `ADMIN_TOKEN`，普通学习不受影响。
- **前端报网络错误** → 确认后端 3001 已启动、前端开发模式 `/api` 会代理到 3001。
- **改了课程 JSON 没生效？** → 内容按请求实时从磁盘读取，改完刷新页面即可，无需重启。
