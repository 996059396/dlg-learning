# ⚡ DLG 电工考证学习系统

一个**开箱即用的电工考证备考平台**：微课精讲 + 服务端判分练习 + 全真模拟考 + 游戏化激励（金币 / 生命 / 错题 SM-2 复习 / 段位排行榜）。

> 面向「低压电工作业证」等电工类考试的刷题与学习场景，内容覆盖电工零基础前置、初级电工理论、考证主线（安全与急救）三大板块。

---

## ✨ 核心特性

| 模块 | 说明 |
| --- | --- |
| 📚 **课程内容** | 3 大课程 / 28 单元 / 703 微课 / 4,991 个知识点与题目节点（含模拟考多选池），内容全部存为 JSON，可自由增删改 |
| 🧮 **服务端判分** | 判分逻辑在服务端（`backend/lib/grading.js`），前端不可篡改；MC / TF / 填空 / 匹配 / 模拟操作等多题型 |
| 📝 **全真模拟考** | 100 题（60 判断 + 30 单选 + 10 多选）/ 45 分钟 / 80 分及格，自动批改 + 错题入库 + 历史成绩 |
| ❤️ **游戏化激励** | 生命值（答错扣血）、金币商店、签到连击、段位排行榜、周结算（每周一 0:00 自动结算） |
| 🔁 **错题 SM-2** | 错题自动进错题本，按 SM-2 间隔复习，逐题复盘 |
| 🛡️ **数据安全** | 密码 scrypt 哈希存储、会话 token 鉴权、判分结果逐节点落库（`node_results`）用于统计 |

## 🏗️ 技术栈

- **后端**：Node.js (≥ 24) + Express + better-sqlite3（SQLite 单文件库）
- **前端**：React 18 + Vite（`/api` 代理到后端 3001）
- **测试**：Node 原生测试脚本链，`npm test` 一键跑全量（内容校验 + 44 接口 + 20 里程碑 + 12 排行榜 + 10 结算 + 16 安全不变量 = **102 断言** + 判分/数据完整性扫描）
- **零外部依赖**：SQLite 单文件、无 Redis / 无消息队列，`node server.js` 即可运行

## 🚀 快速开始

需要 **Node.js ≥ 24**（better-sqlite3 的预编译二进制在 Node 20 上会段错误）。

```bash
# 1. 安装依赖
cd backend  && npm install
cd ../frontend && npm install

# 2. 启动后端（默认 3001）
cd ../backend && node server.js

# 3. 启动前端（开发模式，默认 5173，/api 自动代理到 3001）
cd ../frontend && npm run dev
```

浏览器打开 **http://localhost:5173** 即可开始学习。生产环境直接 `npm run build` 后用后端静态托管 `frontend/dist`。

> 管理端路由（`x-admin-token` 鉴权）需要设置环境变量 `ADMIN_TOKEN`；**未设置时管理接口返回 503 拒绝，学习功能不受影响**。

## 🧪 测试与内容校验

```bash
cd backend
npm test          # 全量门禁：内容校验 + 接口 + 里程碑 + 排行榜 + 结算 + 安全不变量（102 断言）
```

内容质量是核心资产：每一条判分规则都有内容校验器护航（`scripts/validate_content.cjs`），任何课程 JSON 的结构错误 / 判分字段缺失都会在校验阶段暴露，而不是在运行期。
