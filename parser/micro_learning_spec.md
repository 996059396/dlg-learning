# 微学习提取规范 v2（题量×10 难度÷10）

## 核心理念转变
旧版：每 chunk 2 个长 info + 2 道难题 → 新版：每 chunk 1 个短 info + 12~18 道微题

## 节点配方（每个 chunk 生成 13~19 个节点）
1. **开场 info 节点 1 个**：不超过 3 句话！只给出本段最核心的一个概念。禁止长篇大论。
2. **微题 12~18 道**，严格遵循：
   - **前 1/3 超简单**（true_false 为主）：直接从 info 里能找到答案，例如「欧姆定律写作 u=Ri，对吗？」
   - **中 1/3 简单**（multiple_choice 2~3 选项）：同一概念换个说法再问，例如「u=Ri 中的 R 代表什么？电阻/电压/电流」
   - **后 1/3 略有思考**（fill_blank 单字/单词答案 + mc 3 选项）：小小应用，如「2A 电流流过 3Ω 电阻，电压是___伏」（答案 6）
3. **在题中教学**：每道题的 explanation 都要补充一小条新知识或强化记忆口诀，让用户"做完题比做题前多懂一点"
4. **多角度重复**：同一个概念至少出 3 道不同形式的题（判断→选择→填空），螺旋上升
5. **难度红线**：
   - 禁止多步计算（一步乘除可以）
   - 禁止在题干里出现两个以上新概念
   - 禁止"下列说法错误的是"这种否定式绕弯题干
   - 选项数：true_false 2 个，mc 最多 3 个
   - fill_blank 答案必须是 1~3 个字或一个数字

## 节点 JSON 格式
{"type":"info","title":"...","content":"..."}
{"type":"true_false","question":"...","correct_answer":true,"explanation":"..."}
{"type":"multiple_choice","question":"...","options":[{"id":"A","text":"...","is_correct":false},...],"explanation":"..."}
{"type":"fill_blank","question":"...含___空格...","answer":"...","acceptable_answers":["...","..."],"explanation":"..."}
